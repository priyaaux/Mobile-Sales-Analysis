# 📊 Mobile Sales Analysis Dashboard – Power BI

This project presents an interactive **Mobile Sales Analysis Dashboard** built using **Power BI**.
It provides insights into brand performance, customer behavior, sales distribution, and overall business trends.

---

## 🚀 Key Insights Covered

* **Brand-wise Total Sales & Quantity**
* **Payment Method Distribution**
* **City-wise Sales Performance**
* **Customer Ratings Overview**
* **Monthly Sales Trends**
* **Transactions by Brand**
* **KPI Cards**

  * Total Sales
  * Total Quantity
  * Average Sale
  * Total Transactions
